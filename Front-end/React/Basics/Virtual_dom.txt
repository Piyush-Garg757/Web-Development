React Fiber
Fiber is a reimplementation of React’s reconciliation algorithm.
Technically:
Each Fiber is a unit of work
React breaks rendering into small chunks
These chunks can be:
paused
resumed
aborted
prioritized
Think of it like:
Old React  : do everything in one go 😵
React Fiber: do work piece-by-piece 🧠
